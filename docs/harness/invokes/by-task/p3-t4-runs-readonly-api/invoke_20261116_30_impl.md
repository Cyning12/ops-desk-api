### `app/ops/lg_rag/run_store.py` 尾增 P3-T4 节

- `list_thread_runs_page(user_id, thread_id, *, limit, after=None)`：keyset
  WHERE user_id+thread_id+((created_at<ts) OR (created_at=ts AND run_id<rid))
  ORDER BY created_at DESC, run_id DESC LIMIT limit+1。
- `fetch_run_start_queries(run_ids)`：单次 IN 查询取每 run 最小 seq 的 run.start
  帧 payload.query（防 N+1）。
- `fetch_schedule_attributions(run_ids)`：`_ATTRIBUTION_SQL` raw SQL 契约钉名
  （ops_schedule_fires f JOIN ops_schedules s ON s.schedule_id=f.schedule_id
  WHERE f.run_id=ANY(:run_ids) ORDER BY f.fired_at DESC NULLS LAST）；
  except ProgrammingError 且 exc.orig.sqlstate=="42P01"（UndefinedTable）→
  warning + 空归因（R-P3-T4-1 · T2 表缺位降级），其余异常 raise。

### `app/ops/lg_rag/event_store.py` 尾增

- `RUN_EVENTS_ALLOWED_TYPES` 8 值 tuple（run.start/answer/subtask.progress/
  node.progress/hitl.waiting/done/error/hitl.resumed · 契约 §0 白名单）。
- `list_run_events_page(run_id, user_id, *, after_seq=0, limit=500)`：
  assert_run_owned 前置 → WHERE run_id+user_id+seq>after_seq+
  event_type.in_(白名单)（**SQL 层过滤**——R3 裁定：500 帧截断按白名单后帧计数，
  内部帧存在性不可经截断形状侧漏，非白名单 payload 不进应用内存）ORDER BY seq
  LIMIT limit+1 → {events 四字段, truncated, next_after_seq=末帧 seq or None}。
