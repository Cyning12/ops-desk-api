# invoke_30 · impl（p2b-t2-mcp-transport-session）

## 内容

### 新增 `app/ops/capability/mcp/` 六模块

- `errors.py`：`McpError` 基类 + `McpTransportError`（`cause=CAUSE_TRANSPORT` 供
  circuit.is_environmental_failure 计数 · 可传 `CAUSE_HTTP_STATUS`+http_status）/
  `McpTimeoutError`（继承 Transport）/ `McpProtocolError` / `McpHandshakeError` /
  `McpIdentityMismatchError`（继承 Handshake · span reason=identity_mismatch）。
- `jsonrpc.py`：JSON-RPC 2.0 编解码（make_request/make_notification/make_result/
  make_error · is_request/is_notification/is_response · 错误码 -32700/-32600/-32601/
  -32603 · `JsonRpcRemoteError` 无 cause=业务类不计熔断 · id 单调计数）。
- `transport.py`：`McpTransport` Protocol（async request/notify/aclose）+
  `MINIMAL_ENV_KEYS`+`filtered_env`（不继承 os.environ · §5.3）+ `_ResponseMux`
  两传输共用纪律（server→client ping 回 {} · 其余请求立即 -32601 防挂起 · 通知含
  tools/list_changed 忽略）+ `StdioTransport`（create_subprocess_exec · 换行行帧 ·
  EOF/非 JSON→fail_all · aclose terminate→5s→kill）+ `HttpTransport`（httpx 既有依赖 ·
  POST accept json+sse · 202/空体 return · 非 200→CAUSE_HTTP_STATUS · SSE data 帧回流）。
- `session.py`：`SUPPORTED_PROTOCOL_VERSIONS=("2025-06-18","2025-03-26","2024-11-05")`
  · `clamp_timeout_s`（floor 1s/cap 120s/NaN 非正回落默认）· `_McpCircuitSpec`
  （capability_id=mcp.{key} · side_effect 读态 · 熔断按 server 复用 circuit.guard）·
  `McpSession.connect()`（start→握手降级链+应答版本支持集断言+expected_server 精确
  相等校验→ping 门→tools/list · 任一步失败 `_safe_close` 清理半成品含取消）·
  `call_tool`（clamp+guard · 读重试 1 次写禁重试 §5.4）· tools 缓存不重拉。
- `manager.py`：`McpSessionManager`（configs 注入不读 settings）· start() 并发建连
  gather return_exceptions per-server 隔离 warn 跳过 · `_connect_one` 并发去重
  （_inflight 单 flight · 入口 _closed 拒建堵注册窗口竞态）· 迟关闭（aclose 后建完
  即 close 不入池）· 取消感知（CancelledError 清理 transport 重抛）· aclose() 幂等
  逆序 close+unregister_hook 回调（R5c 接口面 · T3 挂点 · hook 失败仅 warn）。
- `__init__.py`：公开导出；import 期零副作用（不起子进程/不建 client）。
